# БУНКЕР ONLINE — инструкция

## Что внутри
- `server.js` — сервер комнат, игроков, карт и голосования.
- `public/` — сайт игры (HTML, CSS, JavaScript).
- `package.json` — зависимости и команда запуска.

## 1. Запуск на своём компьютере
1. Установи Node.js с https://nodejs.org/ (версию LTS).
2. Распакуй архив в отдельную папку.
3. Открой терминал в этой папке.
4. Выполни:
   ```bash
   npm install
   npm start
   ```
5. Открой `http://localhost:3000`.
6. Создай комнату. Друзья в той же Wi-Fi сети могут открыть `http://ТВОЙ-ЛОКАЛЬНЫЙ-IP:3000`.

## 2. Как играть с друзьями через интернет
Для игры из разных сетей сервер должен быть доступен в интернете.
Самый простой вариант для теста:
1. Создай аккаунт на Render.com.
2. Загрузи этот проект в GitHub.
3. В Render выбери **New → Web Service** и подключи репозиторий.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. После публикации Render выдаст адрес вида `https://название.onrender.com`.
7. Отправь этот адрес друзьям. Все заходят по одной ссылке, а код комнаты вводят внутри игры.

На бесплатном хостинге сервер может засыпать при отсутствии активности. Для постоянной игры проверь актуальные условия тарифа хостинга. Не публикуй секреты и пароли в коде.

## 3. Правила текущей версии
- Создатель комнаты становится ведущим.
- Нужно минимум 3 игрока, максимум 12.
- Ведущий нажимает «Начать игру».
- Каждый игрок открывает свои карты по одной.
- Игроки обсуждают характеристики голосом или в чате стороннего приложения.
- Ведущий запускает голосование.
- Каждый живой игрок выбирает одного другого игрока.
- Ведущий завершает раунд; игрок с наибольшим числом голосов выбывает.
- Игра продолжается, пока не останется два выживших.

## 4. Важные ограничения прототипа
Это рабочая стартовая версия, но пока без встроенного текстового/голосового чата, таймера, восстановления после перезагрузки и защиты от повторного голосования. Если несколько игроков набрали одинаковое число голосов, выбывает первый в списке с максимальным результатом. Карты и состояние комнат хранятся в памяти сервера и пропадают после его перезапуска.
